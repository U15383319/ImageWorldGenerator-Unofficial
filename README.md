# ImageWorldGenerator-Unofficial

A Fabric mod for Minecraft 1.20.1 that generates biomes, terrain heights, and structure distribution from image colors, with support for custom color mappings.

This project is an unofficial port of [ImageWorldGenerator](https://github.com/28Pollux28/ImageWorldGenerator), originally developed by 28Pollux28 for Minecraft 1.16.5.
